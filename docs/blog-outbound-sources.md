# Blog outbound sources (rotate for variety)

Past archive overused **NIMH + NCCIH + Apple Support**. New posts must vary.

## Rules
- 2–4 outbound links per post
- Rotate domains; don’t default to the same three every day
- At least one non-(NIMH/NCCIH/generic Apple audio) link when another authority fits
- Sales-upward only (support calm / sleep / sensory / ADHD context / Apple how-tos)

## Credible pool by topic
| Topic | Prefer |
| --- | --- |
| Anxiety / ADHD | NIMH, CHADD, MedlinePlus, PubMed summaries |
| Relaxation / breath | NCCIH, CDC stress pages, clinic explainers |
| Sleep | NHLBI, MedlinePlus sleep, reputable sleep hygiene |
| Sound / hearing / noise | NIDCD, ASHA, Apple Support Sound/Background Sounds |
| Sensory / autism | Reputable autism orgs, sensory-friendly accessibility guides |
| Apple product steps | Specific Apple Support article for Focus, Screen Time, Lock Screen, etc. |
| Clinics | Mayo Clinic, Cleveland Clinic, university health (balanced) |
